Static hosting and local preview
===============================

The site can run on any static host. No hosting provider is assumed and these
files do not deploy anything. Keep index.html, scripts, styles, and assets at
the same relative paths. The preview gallery remains a separate preview.html.

Local preview
-------------
Run python3 serve.py from the sky folder. It binds only 127.0.0.1:8765.
Use --port 8767 for a separate verification server. Restart an existing server
explicitly after changing serve.py; changing the file does not update a process.

The Python server uses only the standard library. HTML, CSS, JS, JSON, SVG and
other small text formats support dynamic gzip, negotiated with Accept-Encoding.
Identity and gzip responses have separate weak ETags, Last-Modified, and
Vary: Accept-Encoding. HEAD reports the selected representation's length without
a body; conditional GET/HEAD can return 304. Brotli is not claimed or required.

MP4 and WebM are never gzip-compressed. Single byte ranges return 206, including
suffix ranges; unsatisfiable ranges return 416. Malformed/multipart ranges are
ignored and return the full representation. If-Range accepts a current HTTP
date; a weak ETag cannot satisfy If-Range and yields a full response.

Caching contract
----------------
HTML always uses Cache-Control: no-cache, meaning it may be stored but must be
validated before reuse. Unversioned files, including vendor audio imports,
also revalidate. A version is recognized for asset URLs with one nonempty v
parameter containing letters, digits, periods, underscores or hyphens, or for
media names ending .mobile-v<digits>.mp4, .webm or .webp.

Those versioned assets use public, max-age=31536000, immutable. This is a
production-style policy: change the query version or filename whenever bytes
at such a URL change. It is not safe to edit a versioned file and reuse its old
URL. Different v values are distinct browser/CDN cache keys but resolve to the
same local pathname; the Python server does not preserve older file versions.
Do not configure a CDN to discard the v query parameter from its cache key.
Do not strip validators on unversioned JS imports. Errors are not immutable.

Nginx deployment example
------------------------
hosting/nginx.conf is an http-context include with map directives and a sample
static server block. Set root to the deployed sky directory and adapt the
listener/server_name to the existing host. Keep existing TLS and other service
configuration in their current configuration; this example supplies neither
certificates nor reverse-proxy/authentication settings.

Nginx supplies conditional requests and byte ranges through its static handler.
The example enables gzip for text and excludes video/image encodings. It uses
the same versioned-asset policy and revalidates HTML and unversioned imports.
Use exactly one v parameter per URL (as the site does); nginx's $arg_v selects
the first occurrence whereas the Python helper requires exactly one value.

Before applying an adapted config, run nginx -t using that host's complete
configuration. No nginx instance is installed or changed by this site package.
Then verify gzip, cache headers, 304 responses and 206 ranges at the actual
public URL; local server results cannot establish another host's behavior.

Examples (replace the origin with the real host):
  curl -I 'http://127.0.0.1:8765/'
  curl -I -H 'Accept-Encoding: gzip' 'http://127.0.0.1:8765/style.css?v=example'
  curl -I -H 'Range: bytes=0-1023' 'http://127.0.0.1:8765/assets/clouds.mp4?v=example'
